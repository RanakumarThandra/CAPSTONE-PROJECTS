## Part B — Predictive modeling

### Stratified Split Justification
The initial profiling showed a significant class imbalance in the target variable `survived`, with roughly 61.6% of passengers not surviving and 38.4% surviving. A stratified train/test split is necessary to ensure that both the training and testing sets maintain this exact same 61.6% / 38.4% proportion. This prevents one of the splits from being disproportionately skewed (e.g., a test set with too few survivors), which would lead to an unreliable evaluation of the model's true real-world performance.

### Imbalance Handling Conclusion
We compared three approaches using a Random Forest classifier:
* **Baseline**: Precision: 0.7869, Recall: 0.6957, F1: 0.7385
* **Class Weight Balanced**: Precision: 0.7778, Recall: 0.7101, F1: 0.7424
* **SMOTE (Train only)**: Precision: 0.7536, Recall: 0.7536, F1: 0.7536

**Conclusion**: SMOTE provided the most balanced performance between precision and recall, raising recall significantly while sacrificing a bit of precision, resulting in the highest F1 score (0.7536). The baseline struggled with recall, missing too many actual survivors. Class weight balancing offered a slight improvement over the baseline, but SMOTE was the most effective strategy for ensuring the minority class was identified accurately.

### Regression Side-Task: Heteroscedasticity Conclusion
The residual plot (`residual_plot.png`) for the multivariate linear regression predicting `fare` shows a clear non-random spread of residuals. As the predicted fare increases, the variance (spread) of the residuals also widens significantly, forming a funnel or cone shape. This indicates the presence of **heteroscedasticity**. The model struggles to accurately predict high fares, likely because the relationship between features and very expensive tickets is non-linear or influenced by unmeasured variables.

### Final Recommendation
I recommend deploying the **Random Forest** classifier. It achieved the highest overall Accuracy (0.8101) and the best F1 Score (0.7385), meaning it provides the most balanced performance between correctly identifying survivors (Recall) and minimizing false alarms (Precision). While Logistic Regression had a marginally higher AUC (0.8427 vs 0.8402), Random Forest's superior recall makes it better suited for an imbalanced dataset where identifying the minority class is critical. The Decision Tree suffered from poor recall (0.5362) and is not recommended.
